# 三平台内容发布助手 R01

用户明确要求正式 Windows 软件，像既有双网盘助手，可由 AI 控制上传和内容运营，并留可扩展接口。当前项目内已安装三平台运行组件，原脚本保留。本轮直接在独立 R01 版本目录实现，冻结既有工具，不要求重新批准已授权开发。

## 选择

采用 Python 应用服务/SQLite + PySide6 原生桌面 + JSON CLI + loopback HTTP API + stdio MCP。没有采用网页套壳（增加运行组件）或只扩展命令菜单（不满足正式桌面要求）。Qt 桌面负责素材/运营/账号/队列/AI接入；三种控制入口共用服务，不拼接 shell。

## 功能与约束

- Windows x64 可双击 EXE，中文界面、图标、托盘，导入视频、编辑事实摘要与三平台文案话题、账号登录/检查、草稿/发布队列、进度/事件和回执。
- 本机 HTTP 仅 127.0.0.1，独立 token，版本化 /api/v1；CLI JSON；MCP tools 调用同 API。提供 OpenAPI、schemas、AI使用Skill、示例。没有任意命令执行接口。
- 素材注册记录 hash；文案生成保存版本；发布需明确平台、账号、动作与可见范围。默认草稿，不默认为公开。幂等键、账号互斥，提交一次；结果未知禁止自动重发。
- 登录/验证码由本人在专用浏览器完成，GUI 可显示二维码和待处理状态。所有等待有界，取消只停止本地操作，不能声称撤回远端稿件。
- 账号状态区分有本地记录与在线检查；草稿、本地暂存、提交受理、审核/已发布分别记录。
- 内容运营可无 Key 使用：素材事实、真实热榜、证据导入、手动编辑、外部AI导出任务和导入结构化成品。可选 OpenAI 兼容模型连接；只发送明确摘要和公开证据，不上传视频。
- B站和抖音公开榜固定来源+时效/字段校验；失败如实报告。小红书默认证据导入，扩展数据provider接口，无虚构热度。标签是候选，核验状态单独保留。
- 源码/环境/日志/版本都在项目内；发布副本排除 Cookie、API Key、账号profile、任务数据库、日志和内部制作记录；保留第三方许可。运行包含依赖，跨机可迁移性需标注实际验证范围。

## 验收

真实 SQLite/HTTP/CLI/MCP测试覆盖注册、导入、幂等、错误、取消、权限、未知结果不重试、日志脱敏；平台动作mock只用于会发生发布的隔离路径。Qt离屏/本机启动和关键操作；构建EXE后在含中文和空格的独立路径运行并经AI API导入素材与运营包，确认GUI显示同状态。线上只读热榜可实测；本轮不重复公开投稿。草稿试传仅沿用已授权的6秒测试范围，如需要扫码再叫用户。
