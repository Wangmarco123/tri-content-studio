# 桌面使用指南 R03

启动软件默认进入“AI 一键方案”。左侧还有“素材库”“文案与证据”“账号与授权”“任务队列”“AI 接入与设置”。首次启动没有演示视频或虚构热榜；先导入自己的视频。

## 推荐主流程：选择视频 → 一键生成 → 选标题 → 保存或草稿

1. 在首屏点击“＋ 导入视频”，或选择已注册的视频。可选填写本次想强调的功能、结果或观众。
2. 保持“自动 · 优先本机 Codex”，点击“一键生成三平台方案”。默认使用本机 Codex 已有的 ChatGPT 登录态；首页会显示实际检测结果。无需先申请 API Key、手工准备 JSON 或在外部 AI 中复制任务。API 兼容模型仍可选。
3. 软件自动提取音轨并转写完整口播，再结合抽样画面分析，不要求先填写摘要、准备字幕或配置语音 API Key。页面按真实后台阶段显示“提取音轨”“完整语音转写”“结合画面与完整口播分析”“查询公开热点”“AI 搜索与匹配生成”“校验并保存文案”。进度来自实际处理记录。可取消本次生成；取消不涉及平台发布。失败会保留真实原因，不用局部转写冒充完整分析。
4. 结果分为五个页签，逐块核对。生成完成后，三平台第一标题候选已经保存为本地文案。
5. 在 B站与小红书方案中选择其他标题候选，点击“保存所选标题到三平台文案”更新本地文案。也可以点击“保存并加入抖音草稿”；B站仍只保存本地，不会自动投稿。

五块结果的用途：

- **借势方向与来源**：方向、关联原因、真实来源链接、查询时间；没有合适热点会明确说明，允许使用自然搜索表达。
- **素材适配理由**：对应片段起止时间、抽帧或字幕或用户事实依据、对应功能/结果，以及不适合借势或需要补充素材的限制。
- **B站方案**：多个标题候选、视频简介、投稿 TAG、独立的文字分区建议。分区建议不是自动确认的投稿分区 ID。
- **抖音方案**：作品文案、独立首句钩子和 #话题。
- **小红书方案**：多个标题候选、短配文、独立搜索关键词与 #话题。搜索词与话题分别展示。

顶部说明实际媒体分析范围。新方案会区分“抽样画面＋全音轨机器转写”“视频无音轨”“全音轨检查未识别出可用人声”。旧历史没有 speech 记录时明确标为旧分析，不能视为已完成自动全音轨转写。抽样画面不代表逐帧完整观看；机器转写也不等于逐字人工核验。热点来源、标题、功能和结果都必须由真实材料支持，不保证爆款或流量。

## 完整口播：查看、查找与复核

方案完成后，点击分析范围旁的“查看完整口播…”。独立窗口不会挤占五块方案结果：

- “全文”保留全部识别文字；“全部时间戳”按每段起止时间显示，不截前 200 句。输入文字可在当前页查找下一处。
- “需复核片段”列出引擎实际标记的低置信片段和提供的识别评分；评分不是准确率。品牌、命令、专有名词和数值尤其需要结合原音频及画面核对。
- 顶部显示处理秒数 / 音轨总秒数、模型、设备和缓存是否命中。完整处理只说明整段音轨已处理，不保证逐字准确；没有被标记低置信也不代表人工核验通过。
- 点击“复制全文”或“复制带时间戳全文”后才写入剪贴板。可用“打开 TXT / SRT / JSON”查看本次方案保存的本地转写文件；文件未返回或已丢失时会禁用或说明原因。
- 无音轨和未识别出人声是正常结果，会按实际画面生成，无需补写空口播。旧方案可查看其分析范围，但不会生成虚构的 ASR 全文。

自动转写使用已安装的本地模型；首次处理较长视频可能需要时间，缓存命中会明确显示。音轨提取或转写失败时先查看真实错误，不会静默跳过并声称完整。

没有合适热点时，第二块仍展示视频内容摘要、三个平台各自的适配理由、实际抽帧时间与分析限制，不会留白。标注为“AI 搜索来源，待独立复核”的链接是 AI 搜索报告，不表示本机已经独立打开并核实原页面。

一键方案会把抽样画面作为图像附件，连同全音轨机器转写、明确事实和公开证据交给所选 AI；不会直接发送整段原视频或本地转写文件路径。没有识别出来的声音内容或未抽到的连续画面，不应据此声称已经分析。

需要更细的文案修改、事实修订、公开证据导入或外部 AI 协作时，再使用下面的补充工作区。JSON 导入导出是高级备用路径，不是默认生成步骤。

## 1. 注册视频和事实资料

在“素材库”点击“＋ 导入视频”，选择成片。软件保留原文件位置并登记文件摘要，原视频不会自动复制到账号或上传目录。导入后会自动选中新视频，不会沿用另一视频的方案。以下资料都是可选补充，不是自动分析的前置条件：

- 摘要：这条视频实际展示或解释了什么。
- 事实：每行一项，只写画面、口播或已有资料能证明的内容。
- 关键词：用逗号分隔视频本身的主题、产品或项目名称。
- 目标人群：这条内容主要适合谁看。

点击“保存素材资料”。文案和任务会引用这条素材；素材变动或丢失时，任务会要求重新导入，避免把旧文案发到另一份文件上。

## 2. 查热点，准备三平台文案

打开“文案与证据”，选择素材和平台。可以输入关键词后点击“获取热榜”，也可以使用“导入证据 JSON”导入带真实来源链接的研究结果。接口不可用或没有返回结果时会明确提示；首屏一键方案还会通过可用的 AI 搜索能力补充公开来源。

热榜仅表示该来源在相应时间的公开榜单或内容快照。请核对来源和抓取时间，判断自己的视频是否确实与热点有关；不把热门关键词、标签候选当成流量保证。

需要使用外部 AI 或留存结构化研究材料时，也可以使用高级备用流程：

1. 点击“导出 AI 文案任务”，保存结构化任务文件。导出的内容包括素材事实和公开证据，不包含视频文件或账号凭据。
2. 将任务交给自己选择的 AI，根据其中的响应格式生成文案 JSON。
3. 使用“导入文案 JSON”导入结果。证据引用、平台和字段不符合要求时，软件会拒绝导入并说明原因。

也可以直接选择平台，在编辑区填写标题、简介或正文、逗号分隔的候选标签，以及热点相关性说明。点击“保存文案版本”。“已有文案”下拉框用于选择要执行的已保存版本。修改后须再次保存，软件不会静默把未保存文字交给发布任务。

有模型接口时，先到“AI 接入与设置”保存 Base URL、模型名称和 API Key，再点击“使用已配置模型生成”。API Key 遮掩显示；留空保留原值，勾选清除才会删除。模型只接收素材摘要、事实和公开证据，不接收成片文件。

## 3. 登录与本人验证

在“账号与授权”选择平台，账号名称默认是 `creator`。点击“扫码登录”会建立登录任务，并打开专用授权流程。请本人完成扫码、短信或验证码。

在“任务队列”选择该任务，可以查看阶段信息；适配器提供本地二维码时，右侧会显示图片。也可在专用浏览器完成操作。“有本地记录”只说明发现本地会话，不等于已经通过在线检查；需要时点击“在线检查”。

各账号使用独立浏览器会话。不要同时用两套程序打开同一个账号 profile，不要清除专用浏览器数据。小红书不再使用专用浏览器或登录资料，仅导出本地文案。

## 4. 保存草稿或明确提交发布

在“文案与证据”选择已保存的文案版本，确认执行账号。默认可见范围为“草稿（默认）”。首屏一键方案不含公开发布按钮。

- “加入草稿任务”执行草稿保存，不会自动切换成公开发布。此操作仅用于抖音；小红书显示“导出小红书人工发布文案”，不创建平台任务。
- B站当前适配器不提供草稿保存，因此对应按钮会禁用。如需真实投稿测试，须明确选择“仅自己可见”，并使用发布操作。
- “按选定范围发布…”仅在明确选择“仅自己可见”或“公开发布”后继续。确认框会显示平台、账号、标题和可见范围，默认取消。确认后只提交一次。

软件对平台不支持的动作或可见范围会明确拒绝，不会改成公开发布。不要把“加入草稿任务”理解为仅在本机保存文案；本机文案编辑保存使用“保存文案版本”。

## 5. 查看结果与取消

“任务队列”展示状态、进度、平台消息与回执。选中一条任务查看详细事件。各状态含义不同：

- 等待执行：尚未开始。
- 待本人操作：需要扫码、验证码或页面确认。
- 草稿已保存：适配器观察到相应草稿结果，仍应按平台说明核对。
- 已提交受理：平台已经接收，不表示审核通过或公开可见。
- 结果待核实：本地观察中断，须核对原页面或平台稿件，不能直接再发一次。
- 已取消：本地操作停止；已经提交的远端稿件不会自动撤回。

“取消所选本地任务”只针对选中的任务。验证或频率限制出现时，应先完成本人验证或停止等待，不能连续重试同一发布。

## 6. 让 AI 使用同一工作空间

“AI 接入与设置”显示当前本机 HTTP 地址。点击“复制地址”和“复制访问令牌”，可交给在本机运行的受信任 AI 客户端；“打开 OpenAPI”提供实际接口说明。令牌只有主动点击复制时才会读取，不在主窗口明文显示。

接口仅监听本机。令牌和模型 Key 不应发到公开聊天、日志或客户文件。AI 与桌面使用相同的素材、文案和任务记录；从其他入口更新后，可用“刷新素材”或“刷新任务”查看当前数据。

## 7. 托盘与退出

系统托盘可用时，点击窗口关闭按钮，可选择“保留到托盘”“退出软件”或“取消”。保留到托盘会隐藏主窗口，任务继续执行；双击托盘图标或选择“显示主窗口”可以恢复。

退出软件会等待本地处理和平台工作进程安全停止，再关闭服务。如果后台尚未停止，窗口会保留并提示原因；此时先查看任务，不要把仍在等待的退出当成已经结束。

本指南描述桌面操作与本地结果查看。登录、真实上传、平台审核、跨电脑运行和客户验收应分别记录，不能由离屏界面检查替代。
