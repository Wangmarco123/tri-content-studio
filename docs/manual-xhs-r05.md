# R05 小红书改为人工发布

版本1.4.0。按用户反馈移除小红书自动操作。B站与抖音的原有能力保留。

1. 选择视频，一键完成完整口播转写、画面分析和三平台文案生成。
2. 在“文案与证据”选择小红书文案。
3. 点击“导出小红书人工发布文案”，保存标题、正文、话题与已有搜索关键词。
4. 本人打开小红书官方App或网页，手动选择视频、粘贴文案并发布。

账号页只显示B站与抖音。小红书文案选中时不显示平台任务与发布按钮。一键加入草稿仅排抖音任务。HTTP与MCP不再提供小红书账号操作；服务层与执行器均拒绝旧调用，程序启动时取消遗留的小红书待执行任务。历史已提交与结果不明的记录保留，未删除远端作品。

旧登录资料与历史版本作为项目内记录保留，不再用于小红书自动访问。处罚情况仅记录为用户反馈，本次不登录小红书核实，也不执行试传。
